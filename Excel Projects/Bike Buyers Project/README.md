# Bicycle Purchasing Behavior

## Overview
This project analyzes a dataset related to **bicycle purchasing behavior**, with the goal of understanding who buys bicycles and what factors influence buying decisions. Using Excel, I explored customer characteristics and purchasing patterns to extract simple, meaningful insights about the market.

## What I Worked On
- Explored the dataset and its structure  
- Analyzed customer attributes related to bicycle purchases  
- Used pivot tables to summarize trends  
- Created basic charts to make insights easier to understand  

## Outcome
The analysis highlights clear patterns in bicycle purchasing behavior and provides a structured overview of the market, useful for basic reporting or decision-making.
